PROJECT // 01

Mind-Quest

Sep 2025 — Dec 2025

An AI-powered quiz platform I built using the MERN stack. The idea came from wanting to make quiz creation easier for teachers — instead of writing questions manually, the app generates them using the Google Gemini API based on any topic. Teachers can create quizzes and track how students perform; students get instant feedback after each attempt.

What I personally worked on Built the full backend in Node.js + Express, integrated Gemini API for quiz generation, implemented JWT-based role auth (teacher/student), and designed the MongoDB schema for quiz results and user tracking.
